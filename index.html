Export & Bilder kopieren

💡 So kopierst du die ausgewählten Bilder:

  1. Klicke auf "Python-Script laden" um copy_images.py herunterzuladen
  2. Speichere das Script im selben Ordner wie deine 4 Bildordner
  3. Klicke auf "CSV Download" und speichere es im selben Ordner
  4. Öffne ein Terminal/Kommandozeile in diesem Ordner
  5. Führe aus: python copy_images.py
  6. Das Script erstellt automatisch final/ mit 4 Unterordnern und kopiert alle ausgewählten Bilder
